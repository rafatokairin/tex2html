# passo-a-passo:
pandoc é uma biblioteca em python que realiza a conversão .tex para .html.

para instalar use o comando: pip install pypandoc --pre

a opção --mathjax gera fórmulas matemáticas em formato mathml. O mathjax é uma biblioteca javascript que é usada para exibir fórmulas matemáticas em páginas da web.

*obs: chame uma vez a função "pypandoc.download_pandoc()" para fazer o download do software pandoc.
